QUESTION Show monthly revenue for the current financial year.
↓
PERSISTENT MEMORIES + SCHEMA RETRIEVED Semantic: Revenue excludes cancelled orders • Procedural: Use invoice_date
↓
GENERATED SQL 
SELECT DATE_TRUNC('month', invoice_date) AS month, SUM(amount) AS revenue
FROM invoices
WHERE status != 'cancelled'
GROUP BY month
ORDER BY month;
