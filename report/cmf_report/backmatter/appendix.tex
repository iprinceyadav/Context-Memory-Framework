\section{API Endpoints}
\label{app:api}
All JSON endpoints are served under \texttt{/api}. Most take \texttt{organization\_id} and
\texttt{user\_id} query parameters (defaults \texttt{default-org} and \texttt{default-user});
``admin'' means role \texttt{owner} or \texttt{admin}.

\section{Running the System}
\label{app:run}
\begin{lstlisting}[language=bash, caption={Installation, start-up, tests and benchmark}, label={lst:run}]
copy .env.example .env          # then set LLM_API_KEY
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
pytest -v tests/
python tests/run_evaluation.py  # writes tests/evaluation_results.json
\end{lstlisting}
After start-up, the web interface is available at \texttt{http://127.0.0.1:8000} and the
interactive API documentation at \texttt{/docs}. A sample database can be connected on the
Connect Database screen by uploading the file or by typing its path, for example
\texttt{sample\_dbs/retail\_store.db}.
